DATOS QUE SE LEEN PRIMERO
1. EMPRESA

3. TOTAL realmente pagado (no confundir con IVA o efectivo entregado)

5. FORMA DE PAGO

REGLAS IMPORTANTES
- El IVA puede tener una sola fila (21%) o varias (4%, 10%, 21%).
- El resumen fiscal con BASE + CUOTA permite comprobar la suma.
- El importe de tarjeta o la entrega de efectivo NO es un producto.
- Si la lectura no permite verificar el total, no se inventa: se pide revisión.
- Una línea fiscal "TOTAL base cuota" no representa el importe pagado.
- Las dudas en productos NO invalidan los datos esenciales correctos.
- El diagnóstico OCR nunca se comparte automáticamente.
